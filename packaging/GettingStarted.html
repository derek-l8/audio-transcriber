Getting started

NPU Scribe transcribes files and microphone recordings, then optionally cleans up the text locally. Python and Git are not needed for the installed app.

1. Download a speech model

Open PowerShell and paste this command. It downloads a small English model into your local application-data folder:

$Worker = Join-Path $env:LOCALAPPDATA 'Programs\NPU Scribe\npu-scribe-worker.exe'
& $Worker models download whisper-tiny.en-int4-ov

If you chose another installation folder, set $Worker to its npu-scribe-worker.exe. Wait for model ready. For lectures, you can download whisper-base.en-int4-ov with the same command instead.

2. Choose whether to use AI cleanup

Cleanup removes filler and fixes grammar. Download its separate model with:

& $Worker models download qwen2.5-7b-instruct-int4-ov

This download is about 4.5 GB and cleanup uses several GiB of RAM. Choose Off for cleanup and formatting if you skip it. Once models are downloaded, transcription and cleanup work offline.

3. Use the app

Open NPU Scribe from the Start menu. Select your speech model and import a recording. Choose Off, Light, or Medium cleanup; file imports start with Light cleanup and Mostly structured formatting. Review the text and export the version you need. Raw stays available.

For MP3, M4A, or MP4 files, get a Windows executable through the FFmpeg download page, extract it locally, and use Choose FFmpeg to select bin\ffmpeg.exe. The decoder executable is separate from this installer.

Dictation starts with Medium cleanup and Mostly prose formatting. Open Live dictation, select your microphone and model, and enable the shortcut. Toggle starts and stops with separate presses; Hold records while the shortcut is held. Wait for Recording before speaking. Your text is saved before insertion into the focused app. Processing begins after you stop.

Updates and your files

Close the app and run the newer installer into the same installation folder. Recordings, models, settings, and transcripts normally live in %LOCALAPPDATA%\npu-scribe; updating or uninstalling the app keeps that folder.

The installer is unsigned, so Windows may show an unknown-publisher warning. Download release files from the project’s GitHub releases. Review important text: transcription and cleanup can make mistakes. Dictation microphone and app compatibility need broader checks.

The app uses Qt/PySide under LGPLv3 and FFmpeg playback libraries under LGPLv2.1 or later. Their notices are in THIRD_PARTY_NOTICES.md, with a rebuild guide. Library sources and build instructions accompany binary releases; you may replace those libraries with compatible modified builds.
